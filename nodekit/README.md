# nodekit

Nodekit is a Terminal User Interface (TUI) for managing Algorand nodes. It provides a comprehensive set of tools for node initialization, configuration, and real-time monitoring.

## Features
- **Node Management**: Start, stop, and upgrade your node.
- **Fast Catchup**: Easily manage and monitor the fast catchup process.
- **Metrics Dashboard**: Real-time visualization of node performance and network statistics.
- **Account & Key Management**: Monitor account status and manage participation keys.
